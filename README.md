# mpvx

一个纯音频 Go TUI mpv 播放器，使用青色与淡紫色强调、独立播放标记和自适应列表布局。

## 使用

要求：`mpv.exe` 已加入 `PATH`。支持 SIXEL 的终端会显示固定为 96×96 像素的内嵌封面；窗口宽度小于 64 列时自动隐藏。建议窗口至少 64 列 × 20 行以显示完整界面。画面异常时可按 `Ctrl+L` 完整重绘。

```powershell
# 递归扫描当前目录下的音频文件，并随机生成播放列表
go run . .

# 也可以混合传入文件和目录
go run . .\music .\podcasts\episode.mp3

# 指定初始排序：random、name 或 path
go run . --sort name .\music
```

支持的扩展名包括：mp3、flac、m4a、aac、ogg、opus、wav、alac、ape、wma、aiff、dsf、dff。

从源码运行，或重新构建可执行文件：

```powershell
go run . .\music\one.flac
go build -o mpvx.exe .
```

如果终端不支持 SIXEL，可禁用封面区域中的图片输出：

```powershell
$env:MPVX_NO_SIXEL = "1"
mpvx.exe .\music
```

快捷键：

| 按键 | 操作 |
| --- | --- |
| ↑/↓、j/k | 移动列表选择，不改变当前播放 |
| Enter | 播放选中的歌曲 |
| Space | 播放/暂停 |
| ←/→、h/l | 后退/前进 10 秒 |
| n/p | 当前播放歌曲的下一首/上一首 |
| +/- | 调整 mpv 播放器音量 |
| PgUp/PgDn | 翻页 |
| Home/End、g/G | 选择首项/末项 |
| c | 定位到当前播放歌曲 |
| / | 在 Help 栏中搜索歌曲并自动移动选择位置 |
| n/N | 搜索生效时跳到下一个/上一个匹配项 |
| s | 在随机、名称和完整路径排序之间切换 |
| t | 循环切换主题，并显示当前主题名称 |
| r | 在列表循环和单曲循环之间切换 |
| Esc | 清除错误提示 |
| q、Ctrl+C | 退出 |

主题顺序：Catppuccin Mocha（默认）、Gruvbox、Nord、One Dark。主题保留终端背景色，切换结果不保存到下次启动。

只有在窗口宽度达到 64 列且使用 `path` 排序时，播放列表才显示相对于歌曲共同根目录的路径，并以加粗的 `/` 分隔目录；共同根目录本身不会显示，路径过长时从左侧截断以保留文件名。`random`、`name` 和窄屏模式只显示文件名。背景高亮表示当前选择项。默认使用列表循环；按 `r` 可在列表循环和单曲循环间切换。文件播放失败时会显示错误，手动选择其他歌曲即可。默认随机排序，可用 `--sort` 修改初始顺序，也可在界面中按 `s` 切换。切换排序不会中断正在播放的歌曲。
